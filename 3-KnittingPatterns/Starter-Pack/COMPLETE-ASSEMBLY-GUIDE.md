```
NEW TECHNIQUE: Cable Knitting
Cables create braided, rope-like textures by
crossing stitches over each other. Uses a
special cable needle to hold stitches temporarily.

Perfect first cable project!
```

**Page 3 - Key Techniques:**
```
TECHNIQUE 1: Using a Cable Needle

The cable needle temporarily holds stitches
while you work others, creating the crossover.

Basic cable pattern (C4F - Cable 4 Front):
1. Slip 2 stitches to cable needle
2. Hold cable needle in FRONT of work
3. Knit next 2 stitches from left needle
4. Knit 2 stitches from cable needle
Result: 4 stitches crossed to the left!

C4B (Cable 4 Back): Same but hold needle in BACK

---

TECHNIQUE 2: Reading Cable Charts

Cables are often shown in chart form.
Each square = 1 stitch
Symbols show which stitches cross over which

Key symbols:
□ = Knit on RS, Purl on WS
• = Purl on RS, Knit on WS
🔀 = Cable crossing (direction shown by arrow)

---

TECHNIQUE 3: Keeping Cable Tension

Cables pull fabric tighter than plain knitting.

Tips:
• Keep stitches loose on cable needle
• Don't pull too tight when crossing
• Block finished piece to even out stitches
```

**Page 4 - Progress Shots:**
```
CHECKPOINT 1: First Cable Complete (2" done)
You should see:
✓ Clear cable twist in center
✓ Reverse stockinette on sides (background)
✓ Cable "pops" forward from background

If cable looks loose: Tighten the first stitch
after working from cable needle

---

CHECKPOINT 2: Midpoint (10" complete)
Cable pattern is repeating beautifully!

Check:
• Cables all twist the same direction
• No missed crossings
• Width is consistent

You're getting faster at cable crossings!

---

CHECKPOINT 3: Almost Done (18" complete)
Final stretch - just 2 more inches!

The cable braid should run continuously
from beginning to end.

Next: Bind off and add button closure!
```

**Page 5 - Finishing:**
```
STEP 1: Bind Off in Pattern
Follow the stitch pattern (knit the knits,
purl the purls) as you bind off for a
seamless edge.

STEP 2: Blocking
Pin headband flat, mist with water, let dry.
This makes cables really "pop"!

STEP 3: Button Closure
Sew button 0.5" from one end.
Create button loop on other end:
- Make loop with yarn
- Secure with stitches
- Test fit before trimming yarn

STEP 4: Weave in Ends
Weave along wrong side of cable pattern
to hide ends within the texture.
```

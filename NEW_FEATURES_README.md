# Welcome to Community Canvas & Pattern Generator! 🎨🧶

Your Abstract Emporium website now features two exciting interactive experiences!

---

## 🎨 Community Canvas

**A Living, Collaborative Artwork**

Every visitor can add one contribution per day to a shared, ever-evolving canvas. Draw brush strokes, place shapes, or add symbolic glyphs. Zoom in to discover hidden patterns and signatures left by other visitors.

### Quick Start:
1. Scroll to the "Community Canvas" section (or click nav link)
2. Choose your tool: Brush 🖌️, Shapes ⬭, or Glyphs ✦
3. Pick a color and size
4. Draw on the canvas
5. Zoom in (scroll up) to see hidden details
6. Export your collective masterpiece!

### Features:
- ✨ Three drawing tools
- ✨ 10x zoom magnification
- ✨ One contribution per day (enforced per device)
- ✨ Hidden signatures revealed when zoomed
- ✨ Older contributions gradually fade
- ✨ Export as PNG
- ✨ Fully persistent (survives refreshes)

---

## 🧶 Procedural Pattern Generator

**Transform Art Into Fiber Crafts**

Upload any image (your own or from the gallery) and instantly generate knitting, crochet, and weaving patterns. Perfect for turning abstract art into embroidery, cross-stitch, or other fiber arts projects!

### Quick Start:
1. Scroll to "Pattern Maker" section (or click nav link)
2. Upload an image or select from gallery
3. Adjust complexity if desired (default: Medium)
4. View three pattern types instantly
5. Download each pattern as PNG
6. Use with your knitting/crochet/weaving projects!

### Features:
- ✨ Upload custom images
- ✨ Select from gallery
- ✨ Auto color analysis
- ✨ Three pattern types: Knitting, Crochet, Weaving
- ✨ Five complexity levels
- ✨ Real-time pattern updates
- ✨ Download as PNG
- ✨ Stitch legends included

## 💡 Tips

### Community Canvas Tips:
- One contribution per day keeps things fair
- Zoom in 3x+ to see user signatures
- Share your favorite canvas states by exporting
- Each visitor's device gets its own daily limit

### Pattern Generator Tips:
- Complex images generate better patterns
- Minimal mode = sparse, fast to create
- Dense mode = detailed, small grid cells
- Chaotic mode = artistic, intricate
- Save patterns to reference later

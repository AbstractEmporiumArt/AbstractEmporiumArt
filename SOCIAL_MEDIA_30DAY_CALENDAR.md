---

## OVERVIEW

This 30-day calendar provides:
✓ **Daily social media posts** ready to publish
✓ **Platform-specific variations** (Instagram, Pinterest, TikTok, Facebook)
✓ **AI image generation prompts** for each post
✓ **Call-to-action optimization** (bundle links)
✓ **Hashtag strategies** for each platform
✓ **Scheduling recommendations** (best times to post)

**Content Distribution:**
- Instagram: 5 posts/week (Carousel + Reels)
- Pinterest: 3 pins/day (evergreen focus)
- Facebook: 2 posts/day (community + educational)
- TikTok/Threads: 2 videos/week (educational, behind-the-scenes)
- Blog/Website: 3 posts/week (repurpose social content)

---

## PLATFORM SPECIFICATIONS

### Instagram Best Practices
- **Reels:** 15-30 seconds, engaging hook in first 3 seconds
- **Carousels:** 3-5 slides, swipe-up incentive on last slide
- **Stories:** 4-5 per day, interactive (polls, Q&A)
- **Captions:** 3-5 sentences, 1-2 calls-to-action
- **Hashtags:** 20-30, mix of popular + niche
- **Best times:** 6-9 AM, 12-1 PM, 5-7 PM (Mon-Fri)

### Pinterest Best Practices
- **Pin dimensions:** 1000x1500 (vertical)
- **Video pins:** 15-30 seconds
- **Description:** 100-150 characters, keyword-rich
- **Hashtags:** 5-10, #knittingforbeginners trending
- **Scheduling:** Use Tailwind, 3-5 pins/day evergreen
- **Best times:** Morning + evening (less important than consistency)

### Facebook Best Practices
- **Post length:** 3-5 sentences (longer okay in comments)
- **Videos:** Autoplay optimized (captions essential)
- **Community focus:** Testimonials, user success stories
- **Engagement:** Respond to comments in first 1 hour
- **Best times:** 1-3 PM, 7-9 PM weekdays
- **Group strategy:** Post in knitting groups (cross-promotion)

### TikTok Best Practices
- **Video length:** 15-60 seconds (trending length varies)
- **Hook:** First frame must stop scroll (3 seconds)
- **Trending audio:** Use trending sounds (boosts algorithm)
- **Captions:** On-screen text + voiceover
- **CTAs:** Soft (link in bio, reply, follow for more)
- **Posting:** 3-5x per week, consistent times

## ANALYTICS & OPTIMIZATION

### Metrics to Track

```
Per post:
- Impressions (reach)
- Engagement rate (likes, comments, shares)
- Click-through rate (CTR to website)
- Saves (especially Pinterest)
- Shares (viral indicator)

Weekly:
- Follower growth
- Engagement average
- Traffic from social
- Conversion rate (social → purchase)

Monthly:
- Content pillar performance
- Best performing post types
- Seasonal trends
- Audience insights
```

### A/B Testing Framework

```
Test 2-3 variations per week:
- Subject line/caption style
- CTA button text
- Image style (photo vs graphic)
- Hashtag sets
- Posting times

Track performance for 2 weeks before declaring winner.
Implement winning variation across similar posts.
```

## Now Deploy to Cloudflare Pages (2 minutes)

### Step 1: Open Cloudflare Dashboard
Go to: https://dash.cloudflare.com/

### Step 2: Create Pages Project
1. Click **"Pages"** in the left sidebar
2. Click **"Connect to Git"** button
3. Select **"GitHub"**
4. Click **"Install & Authorize"**

### Step 3: Select Your Repository
1. Find and select **"AbstractEmporiumArt"** repository
2. Click **"Begin setup"**

### Step 4: Configure Build Settings
- **Project name**: `abstractemporium` (or your choice)
- **Production branch**: `main`
- **Build command**: (leave empty - static site)
- **Build output directory**: `/`
- **Environment variables**: (none needed)

### Step 5: Deploy!
Click **"Save and Deploy"**

### Your Live Site
Once deployed, you'll get a URL like:
```
https://abstractemporium.pages.dev
```

Or point a custom domain to Cloudflare.

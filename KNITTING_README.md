## 🚀 QUICK START (7 Days to Launch)

### Day 1: Create Free Guide
- Make 1 simple scarf pattern PDF
- Add materials guide and tips
- **Time:** 3-4 hours

### Day 2: Set Up Payments
- Sign up for Lemon Squeezy or Gumroad
- Create 4 products (bundles)
- Get checkout URLs
- **Time:** 2-3 hours

### Day 3: Connect Email
- Sign up for ConvertKit or Mailchimp
- Create automation sequences
- Connect to website form
- **Time:** 2 hours

### Day 4: Create Beginner Bundle
- 3 patterns (scarf, slippers, headband)
- Stitch cheat sheet
- Materials guide
- **Time:** 4-5 hours

### Day 5: Test Everything
- Walk through full customer journey
- Fix any bugs
- **Time:** 1-2 hours

### Day 6: Generate AI Images
- Create bundle covers
- Make social media images
- Use MidJourney, Canva, or DALL-E
- **Time:** 3-4 hours

### Day 7: Schedule Social Media
- Upload first week of posts
- Use Later.com or Buffer
- Set to auto-publish
- **Time:** 2-3 hours

**TOTAL TIME: ~20 hours over 7 days**

## Troubleshooting

**PDF won't download?**
- Check file size isn't corrupted
- Try opening locally first
- Re-upload if needed

**Email not arriving?**
- Check spam folder
- Verify email address in order
- Check Lemonsqueezy delivery email settings

**Wrong payment link?**
- Copy directly from Lemonsqueezy product page
- Don't edit the URL
- Test the link in incognito window

**Caption:**
```
STEP 1: Create a Slip Knot

1. Hold working yarn (from ball) about 6 inches from the end
2. Make a loop with the yarn (like a pretzel shape)
3. The tail end should hang down visibly

TIP: Leave at least 6" tail for weaving in later!
```

**Image 2:**
- **`FreeBeginnerPatternPhoto3SlipKnotStep2AbstractEmporium.png`**

**Caption:**
```
STEP 2: Complete the Slip Knot

1. Pull working yarn through the loop
2. Tighten by pulling both ends
3. Leave the loop loose enough to slide on needle

This creates your first "stitch"!
```

1. Hold needle with slip knot in right hand

3. Wrap working yarn over left index finger

## 📄 PAGE 6 - KNIT STITCH (The Main Technique)

### Images to Use (3 images):

**Image 1:**
- **`FreeBeginnerPatternPhoto9KnitStitchInsertionAbstractEmporium.png`**

**Caption:**
```
STEP 6: Insert Right Needle

1. Hold needle with stitches in left hand
2. Insert empty right needle into first stitch
3. Go from FRONT to BACK (needles form an X)
4. Working yarn stays behind the work
```

**Image 2:**
- **`FreeBeginnerPatternPhoto10KnitStitchYarnWrapAbstractEmporium.png`**

**Caption:**
```
STEP 7: Wrap the Yarn

Wrap working yarn COUNTERCLOCKWISE around
right needle. This is the most important step!

Direction matters: Under and around the back.
```

**Image 3:**
- **`FreeBeginnerPatternPhoto11KnitStitchPullThroughAbstractEmporium.png`**

**Caption:**
```
STEP 8: Pull Through & Complete

1. Pull right needle back through the stitch
2. Bringing the wrapped yarn with it
3. Slide old stitch off left needle
4. New stitch is now on right needle!

REPEAT for every stitch across the row.
```

## 📄 PAGE 7 - KNITTING INSTRUCTIONS

### Text-Only Page (or small technique reminder image):

```
SCARF PATTERN INSTRUCTIONS

CAST ON: 20 stitches

PATTERN:
Row 1: Knit all stitches
Row 2: Knit all stitches
Row 3-200+: Continue knitting every row

This creates "garter stitch" - a bumpy, 
textured fabric that's reversible!

WHEN TO STOP:
Knit until scarf measures 60 inches
(or desired length - try it around your neck!)

You'll need to start your second ball of yarn
about halfway through the project.

JOINING NEW YARN:
Simply start knitting with the new ball,
leaving 6" tails from both old and new yarn.
Weave these in at the end.

---

COMMON BEGINNER MISTAKES:

✗ Dropped stitch? Don't panic! 
  Use a crochet hook to pull it back up.

✗ Accidentally added stitches?
  Count stitches every few rows. Should always be 20.

✗ Edges getting tight?
  Keep first and last stitch of each row loose.

✗ Tension uneven?
  This is normal! It improves with practice.
```

## 📄 PAGE 8 - BINDING OFF & FINISHED PROJECT

### Images to Use (1-2 images):

**Image 1:**
- **`FreeBeginnerPatternPhoto12BindingOff&FinishedScarfAbstractEmporium.png`** (top half)

**Caption:**
```
STEP 9: Binding Off (Finishing)

When scarf reaches desired length:

1. Knit first 2 stitches normally
2. Insert left needle into first stitch on right needle
3. Lift first stitch over second stitch and off needle
4. Knit one more stitch
5. Repeat steps 2-4 until 1 stitch remains
6. Cut yarn (leaving 6" tail), pull through last loop

WEAVING IN ENDS:
Thread yarn needle with tail, weave under 
stitches on wrong side for 3-4 inches, trim excess.
```
